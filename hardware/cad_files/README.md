# Borinot: Printing parts guide

This document explains how to print the 3D parts of Borinot and some tips to clean them.

It is divided in assembly sections and a general one with cleaning tips.

## General cleaning tips

To clean the parts, the following tools should be used: 
- pliers.
- cutting pliers.
- flathead screwdrivers.
- pointed tools.
- a good deal of patience.

It will be necessary to apply some force to remove the printing supports (the less dense white plastic), but this should be done carefully, especially in more delicate areas.

If any imperfections are found in the holes, a drill may be used to correct them.

## Motor case printing

The CAD files of motor case parts are [main_body/motor_holder_*.STEP](./main_body/) files. To know wich file is for wich motor part check the [motor case table](../2_airframe_assembly.md) in airframe assembly guide.
